## 3. Q-Spatial +8.9pt 的翻转分析（逐题配对，n=101）

| 项 | 值 |
| --- | --- |
| A800 成功 / K100 失败 | 15 题 |
| K100 成功 / A800 失败 | 6 题 |
| **跨阈值翻转（一侧 ratio<2、另一侧 ≥2，即 ratio≈2 边界）** | **19/101 题** |
| ratio 中位数 | K100 1.72 / A800 1.59 |
| ratio 均值 | K100 2.57 / A800 2.35 |

**判读**：净差 9 题中的绝大部分来自 **ratio≈2 判定边界上的翻转**（19 题处在线界附近）。
Q-Spatial 是"长链自由推理 + 数值估计 + 硬阈值"任务：两条各自数百 token 的推理链在
bf16 下只要有极微小分歧（批组成归约顺序、vLLM/torch 版本差 0.15.1-dcu vs 上游、
2.9.0 vs 2.9.1），末位数值估计就会越过 ratio=2 边界。**RoboSpatial 同条件仅差 0.86pt、
且 A800 侧表现出完全相同的保守偏置（compat 41.0 vs 42.9），不支持"K100 存在系统性
算子错误"**；两侧单侧各只跑了一次，该差亦含单次运行噪声。结论方向不变：
论文 73.53 的缺口两侧都存在（A800 仍 −4.2pt），属 bench 配置/模型侧。

## 3.1 服务参数对齐实验（2026-10-30 凌晨，+8.9pt 的分解）

首次 A800 跑沿用 `serve_vllm.sh` 默认参数，与 K100 评测服务**存在三处不对齐**：

| 参数 | K100 评测服务 | A800 首次 | 影响 |
| --- | --- | --- | --- |
| `--max-num-batched-tokens` | 4096 | 默认 | 批内归约顺序 |
| `--max-num-seqs` | 64 | 默认(1024) | 批内归约顺序 |
| `--no-enable-prefix-caching` | 关 | 开（默认） | KV 复用语义 |
| 客户端并发 | 16 | 8 | 批组成 |

将 A800 服务按 K100 参数完全对齐（4096/64/关前缀/ctx 32768）并以并发 16 重跑：

| 配置 | 成功率 |
| --- | --- |
| K100（DCU 定制 vLLM，K100 参数） | 60.4%（单次） |
| A800 首次（上游 vLLM，**默认参数**） | 69.3%（单次） |
| A800 对齐重跑（上游 vLLM，**K100 参数**） | 65.35%（单次） |
| A800 对齐第 3 次（**同配置重复**） | **58.42%** → 见下方修正 |

> ⚠️ 上表为**单次运行**对比；第 4 行（同配置重复）证明单次噪声 ±3.5pt 量级，
> 故"对齐回落 3.95pt"不能确认为参数效应。多次重复均值见 §3.2。

### 3.2 双侧同配置重复（2026-10-30 定案）

K100 侧同配置重复（r2、r3，`tools/run_qs_repeat.sh`，并发 16 与原跑一致）已完成。
全部 6 次运行汇总：

| 平台 | 配置 | 各次成功率 | 均值 ± sd |
| --- | --- | --- | --- |
| K100 (DCU 定制 vLLM) | K100 serving 参数 | 60.40 / 62.38 / 65.35% | **62.7 ± 2.5pt**（n=3） |
| A800 (上游 vLLM) | 对齐 K100 参数 | 65.35 / 58.42% | **61.9 ± 4.9pt**（n=2） |
| A800 (上游 vLLM) | 默认参数（参考） | 69.3%（n=1） | —（单次，与对齐均值差 7.4pt 但在 2σ 内） |

**最终定案**：

1. **跨平台差异：不存在。** K100 均值 62.7% vs A800 对齐均值 61.9%，Δ0.8pt，
   远在两侧运行噪声（sd ~2.5pt）之内。最初的 "+8.9pt" **完全是单次运行对比的
   伪影**；"服务参数效应"与"构建差异"两个推断均**撤回**。
2. **单次运行不确定度：±2.5pt（sd）/ 极差 ~5pt**（101 题、千 token 长链、greedy）。
   任何使用该基准分数的场合必须标注此不确定度，跨平台/跨配置比较必须 n≥3 取均值。
3. **与论文 73.53 的缺口真实存在**：K100 均值 62.7%，差 **−10.8pt ≈ 4σ**，
   超出噪声解释范围 → 归因为**提示引导/模型估计质量/bench 配置**（官方模板间
   变体实验差 21.8pt，`reports/20` §2.4），与平台无关。
4. 方法论教训（对其他长链推理基准适用）：bf16 + 连续批处理下，即使 greedy 解码，
   批组成时变也会让长链在近似平局 token 处分歧——**短答案基准（CV-Bench/RoboSpatial）
   的跨平台一致性结论不能外推到长链基准**。

**分解结论**：+8.9pt ≈ **4.0pt 服务参数不对齐**（对齐后 A800 自身回落 3.95pt，实证）
+ **~5pt 构建/版本数值差异与两侧各自单次运行噪声**（DCU 定制 0.15.1 vs 上游 0.15.1、
torch 2.9.0 vs 2.9.1；长链推理放大微小数值分歧）。剩余部分需双侧同配置重复运行进一步
剥离（K100 当前无卡，待补）。**对验收结论无影响**：对齐后 A800 65.35% 距论文仍差
8.2pt，"与论文缺口主因在 bench 配置/模型侧"成立；该实验同时确立了一条可迁移的
经验——**跨平台精度对比前必须先对齐 serving 参数**，否则批组成差异即可造成数 pt 量级的
表观差距。

> ⚠️ **2026-10-30 自我修正（同配置重复实验后）**：上述分解**基于单次运行对比，
> 统计上不成立**。A800 对齐配置下重复第二次得 **58.42%**（与第一次 65.35% 差
> **6.9pt**，原始输出仅 17/101 逐字一致，23 题翻转）。即 Q-Spatial 单次运行的
> 链分歧噪声即达 **±3.5pt 量级**（机制：greedy 下批组成随到达时机变化 → 千 token
> 长链在近似平局 token 处分歧 → 最终数值估计实质重掷）。据此：
> * "4pt 服务参数效应"为 ~1σ 水平，**不能从单次对比确认**；
> * K100 60.4%（单次）vs A800 对齐两次均值 61.9% —— **无可辨识的跨平台差异**，
>   此前"~5pt 构建差异"推断**撤回**；
> * 可靠结论只剩一条：**跨平台/跨配置比较必须多次重复取均值**（该基准 n≥4/侧），
>   单次分数应标注 ±3.5pt 量级不确定度。K100 侧重复（r2/r3）已排入，见 §3.2。

## 4. 结论

1. **RoboSpatial：跨硬件一致**（Δ0.86pt，逐子项同向）。"62 vs 73.03"的缺口在
   NVIDIA 上同样存在，且保守偏置（GT=Yes 答 no）两侧一致 → **bench 配置差异**
   （官方 harness 提供深度输入通道；喂深度后 compat +13pt，见 `reports/20` §2.3 诊断）。
2. **Q-Spatial：跨平台差异不显著（修正后结论）**。同配置同硬件两次重复差 6.9pt
   （65.35% vs 58.42%，原始输出 17/101 逐字一致）→ 单次运行链分歧噪声 ±3.5pt 量级；
   K100 60.4%（单次）与 A800 对齐均值 61.9% 无可辨识差异，**不存在可证实的
   "构建/版本数值差异"**；与论文的缺口两侧同向存在（A800 对齐均值 −11.6pt），主因仍是
   **提示引导/模型估计质量**（官方模板间差 21.8pt 的变体实验见 `reports/20` §2.4）。
   方法论教训：长链推理基准的跨平台/跨配置比较必须多次重复取均值（n≥4/侧），
   单次分数须标注 ±3.5pt 量级不确定度；serving 参数对齐仍是对比的前提。
3. **K100 推理保真度**：本组证据 + CV-Bench 的 A800↔DCU 对照（99.6% 逐题一致、
   Δ0.1pt，`reports/19_a800_cross_validation.md`）共同支持——**K100 vLLM 适配
   未发现算子或运行时级别的精度缺陷**；各基准与论文的偏差均有 bench/模型侧归因。
